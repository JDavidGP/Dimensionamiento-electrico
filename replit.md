# Ejecutar en Replit

- La aplicación usa React y Vite; no requiere backend ni claves externas.
- El flujo de trabajo de Replit ejecuta `npm run dev` y sirve la vista previa en el puerto 5000.
- Para comprobar la compilación de producción, ejecuta `npm run build`.
- Para trabajar localmente, instala dependencias con `npm install` y luego ejecuta `npm run dev`.
